# Work Plan

GUARDIAN started on 1 July 2026, and its six-month implementation runs to
31 December 2026.

The work is organized into five work packages, on a month-relative
timeline (M1 = July 2026, M6 = December 2026):

| Work Package | Title | Timeline |
|---|---|---|
| WP1 | Protocol, ethics, data boundaries and partner onboarding | M1–M2 (July–August) |
| WP2 | Core Ratio1 toolkit implementation | M2–M3 (August–September) |
| WP3 | Energy-sector validation with MONSSON: renewable-storage / virtual-power-plant advisory monitoring | M3–M5 (September–November) |
| WP4 | Operations-center co-pilot demonstrator with Hyperfy (GOC) | M4–M5 (October–November) |
| WP5 | Evaluation, dissemination and handover | M6 (December) |

Current work focuses on the two validation scenarios; see the
[November 2026 update](/blog/guardian-progressing-with-monsson-and-hyperfy).

See [Deliverables](./deliverables.md) for the outputs each work package
feeds into.
