# Objectives

GUARDIAN pursues five objectives over the project period:

1. **Build the toolkit.** Assemble a reusable software toolkit for deploying
   and operating resource-aware AI workloads on commodity edge and low-end
   VPS infrastructure.
2. **Define the benchmark protocol.** Specify a common, repeatable protocol
   for measuring resource footprint (CPU, memory, latency, energy proxy) and
   output quality across execution profiles — low-power edge, low-end VPS,
   local server, and central/cloud.
3. **Validate in a primary monitoring context.** Apply the toolkit and
   benchmark to an advisory monitoring scenario in the renewable-storage /
   virtual-power-plant space (energy sector), using generic scenario and
   workload descriptors rather than any single deployment's specifics.
4. **Demonstrate transfer.** Show that the same toolkit and benchmark
   protocol transfer to a second, structurally different scenario: an
   operations-center co-pilot demonstrator (physical-security sector).
5. **Deliver a results handover package.** Package the toolkit, benchmark
   protocol, validation reports, and a public summary so the results can be
   reused beyond the project.

See [Expected Outputs](./outputs.md) for how these objectives map to
concrete deliverables.
