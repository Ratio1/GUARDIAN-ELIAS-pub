# Operations-Center Co-Pilot Demonstrator (Physical-Security Sector)

This use case demonstrates transfer of the GUARDIAN toolkit and benchmark
to a structurally different monitoring context: an operations-center
co-pilot that surfaces relevant information from operational feeds to a
human operator in a physical-security setting.

**Boundaries:** this use case is **advisory-only**. It does not perform
live asset control, does not take automated enforcement actions, and does
not perform biometric identification of any kind. Its output is
information for a human operator to review and act on, not an autonomous
control signal.
