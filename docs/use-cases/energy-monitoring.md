# Renewable-Storage / Virtual-Power-Plant Advisory Monitoring (Energy Sector)

This use case applies the GUARDIAN toolkit and benchmark to advisory
monitoring in the renewable-storage / virtual-power-plant space: watching
operational data from distributed storage and generation assets and
surfacing what a human operator should look at.

**Boundaries:** this use case is **advisory-only**. It does not perform
live asset control, does not take automated enforcement actions, and does
not perform biometric identification of any kind. Its output is
information for a human operator to review and act on, not an autonomous
control signal.
