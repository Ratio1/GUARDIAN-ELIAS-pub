# Expected Outputs

GUARDIAN will deliver the following outputs by the end of the project
period on 31 December 2026:

- **Benchmark protocol** — the common measurement protocol for comparing
  resource footprint and output across execution profiles, with a
  data-contract template.
- **Toolkit prototype** — the resource-aware Ratio1 edge/VPS toolkit with
  reproducible configuration notes.
- **Validation reports** — the primary validation report for the energy
  sector with MONSSON and the operations-center co-pilot demonstrator
  report with Hyperfy (GOC).
- **Data specifications** — data contracts, dataset cards and
  synthetic-data generation specifications and, where partner, privacy,
  IP and licensing permissions allow, a small non-sensitive data package.
- **Final report, public summary and demo video** — the project's final
  account of its approach and findings, a plain-language summary and a
  short demonstration.
- **Handover package** — the combined outputs, packaged for reuse of the
  results beyond the project.

Any published data is limited to synthetic, anonymized, aggregated or
partner-approved derived examples. Raw operational data, security media
and incident records are not published.

The project starts from technology readiness level (TRL) 4 and targets
TRL 5 through validation in an industrially relevant environment. TRL 5
is a target, not a claim of current maturity.

Outputs approved for public release will be published on the
[Results & Downloads](../results/index.md) page. See
[Deliverables](../project/deliverables.md) for how they map to D1–D5.
