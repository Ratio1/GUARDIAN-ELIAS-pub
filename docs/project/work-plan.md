# Work Plan

The project period is July–December 2026 as planned in the submitted
application and subject to confirmation in the signed sub-grant agreement.

The work is organized into five work packages, on a month-relative
timeline (M1 = first month of the project period):

| Work Package | Title | Timeline |
|---|---|---|
| WP1 | Benchmark protocol & data contracts | M1–M2 |
| WP2 | Toolkit prototype | M2–M3 |
| WP3 | Primary validation — energy sector | M3–M5 |
| WP4 | Transfer demonstrator — operations centers | M4–M5 |
| WP5 | Reporting & handover | M6 |

See [Deliverables](./deliverables.md) for the outputs each work package
feeds into.
