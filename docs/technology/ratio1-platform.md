# The Ratio1 Platform

GUARDIAN's toolkit is being built on **Ratio1**, a decentralized edge AI
platform. Ratio1 edge nodes are designed to run containerized AI
workloads close to where data is produced, rather than shipping data to a
central data center for every inference.

Many Ratio1 components are published on GitHub; licence and release terms
vary by repository. Public sources for the platform:

- Website: [ratio1.ai](https://ratio1.ai)
- Source code: [github.com/ratio1](https://github.com/ratio1)

GUARDIAN uses the Ratio1 platform as the execution layer for its toolkit;
see [Toolkit & Benchmark](./toolkit-benchmark.md) for how GUARDIAN's own
components fit on top of it.
