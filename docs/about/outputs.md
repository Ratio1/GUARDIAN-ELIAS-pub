# Expected Outputs

GUARDIAN targets the following outputs by the end of the project period:

- **Toolkit** — the reusable software toolkit for resource-aware AI workload
  deployment described in the [objectives](./objectives.md).
- **Benchmark protocol** — the common measurement protocol for
  resource-footprint and quality comparison across execution profiles.
- **Validation reports** — findings from applying the toolkit and benchmark
  in the project's monitoring and transfer scenarios.
- **Public summary** — a plain-language summary of the project's approach
  and findings.
- **Demo video** — a short demonstration of the toolkit and benchmark in
  use.

These outputs are produced targeting **TRL 5** as an ambition for the
underlying technology by the end of the project period; this is a target,
not a claim of current maturity.

Release-approved artifacts will be published as they become available on
the [Results & Downloads](../results/index.md) page.
