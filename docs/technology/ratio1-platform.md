# The Ratio1 Platform

GUARDIAN's toolkit runs on the **Ratio1** platform, a decentralized edge AI
platform. Ratio1 edge nodes run containerized AI workloads close to where
data is produced, rather than shipping data to a central data center for
every inference.

Ratio1's components are open source and published on GitHub. Public
sources for the platform:

- Website: [ratio1.ai](https://ratio1.ai)
- Source code: [github.com/ratio1](https://github.com/ratio1)

GUARDIAN uses the Ratio1 platform as the execution layer for its toolkit;
see [Toolkit & Benchmark](./toolkit-benchmark.md) for how GUARDIAN's own
components fit on top of it.
