# Objectives

GUARDIAN pursues five objectives over its six-month project period
(July–December 2026):

1. **Build the toolkit.** Build a reusable, resource-aware Ratio1 toolkit
   for deploying and operating selected operational AI workloads on
   commodity edge and low-end VPS infrastructure.
2. **Define the benchmark protocol.** Specify a common, repeatable
   protocol that uses a scenario-workload pair as its unit of measurement
   and records latency, data transfer or locality, resource-footprint
   proxies, audit records and human-review status across execution
   profiles — low-power edge, low-end VPS, local server, and
   central/cloud.
3. **Validate in the energy sector.** Validate the toolkit in a primary
   renewable-storage or virtual-power-plant monitoring context with
   MONSSON, using approved partner, derived or synthetic data.
4. **Demonstrate transfer.** Show that the same toolkit and benchmark
   transfer to one bounded operations-center co-pilot scenario for
   physical-security workflows with Hyperfy (GOC).
5. **Deliver a results handover package.** Package the benchmark
   protocol, toolkit prototype, validation reports, public summary, demo
   video and data specifications so the results can be reused beyond the
   project, including by ELIAS.

Both validation scenarios are advisory-only: operators stay in control,
with no live asset control, automated enforcement, live dispatch or
biometric identification.
